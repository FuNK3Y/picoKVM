# picoKVM rev A — thermal-relief justification (current routed board)

KiCad's default asks for at least 2 thermal spokes from a pad into a copper
pour.  With that default, the 6 GND pads below have a single spoke into the
*outer* (F/B) GND pour, so the project sets `min_resolved_spokes = 1`.  The
table proves, from the filled copper of the final board, that each pad is
joined to the solid **In1 GND plane** independently of that spoke (generated by
`hw/thermal_report.py`, re-run on every layout; this replaces all earlier
lists).

| pad | type | connection to the In1 GND plane | other GND copper |
|---|---|---|---|
| C24.2 (56.5, 38.12) | SMD | 1 track(s); via (56.50, 37.36) on In1 fill: yes | spoke into F.Cu pour: yes |
| J9.15 (69.78, 14.0) | plated through-hole (drill 1.00 mm) | barrel joined to In1 fill: **yes** | spokes into F.Cu, B.Cu |
| R2.2 (98.5, 9.42) | SMD | 1 track(s); via (99.27, 9.42) on In1 fill: yes | spoke into F.Cu pour: yes |
| U10.1 (77.1, 59.25) | SMD | 1 track(s); via (76.15, 58.74) on In1 fill: yes | spoke into F.Cu pour: yes |
| U13.8 (28.7, 21.75) | SMD | 1 track(s); no via on its own track; track to U13.3 (whose via (29.78, 21.75) is on In1 fill: yes) | spoke into F.Cu pour: yes |
| U9.1 (51.1, 59.25) | SMD | 1 track(s); via (50.15, 58.74) on In1 fill: yes | spoke into F.Cu pour: yes |

**Outer-pour scraps ("isolated islands"):** pieces of F/B GND pour that touch
only one of these pads.  Each is grounded through that pad, which itself joins
In1 (table above): grounded copper, not floating, and not part of any DC or
low-frequency current path (it may carry small high-frequency return currents,
like any pour).

- U10.1 F.Cu: 2.93 mm2 at (74.6,57.9)-(77.5,61.0), grounded only through U10.1
- U9.1 F.Cu: 1.43 mm2 at (49.1,57.9)-(51.1,59.5), grounded only through U9.1
