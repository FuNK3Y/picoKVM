picoKVM installer

Installs the latest picoKVM firmware from the browser, then connects it to Wi-Fi.

  1. Plug the board's AUX / FLASH USB-C port into this computer.
  2. Hold BOOT, press RESET, release BOOT.
  3. Click Connect, pick the board's port, and install. Accept to erase the device: the firmware's flash layout needs it, and it also deletes the settings.
  4. Press RESET once the install is done. If the Wi-Fi step does not show up, click Connect again and pick the board's port: the running firmware has its own.
  5. Choose the Wi-Fi network, then Visit device opens its settings page: set the admin password and the monitors there.
This browser cannot talk to USB devices: use Chrome or Edge on a computer. The page must be opened over HTTPS.

Already installed? Connect also changes the Wi-Fi network of a running picoKVM.
