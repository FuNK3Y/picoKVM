picoKVM installer

Installs the latest picoKVM firmware from the browser, then connects it to Wi-Fi.

  1. Plug the board's AUX / FLASH USB-C port into this computer.
  2. Click Connect, pick the board's port (USB JTAG/serial debug unit), and install. Accept to erase the device: the firmware's flash layout needs it, and it also deletes the settings.
  3. Once installed, the board restarts and the installer offers to connect it to Wi-Fi. Visit device then opens its settings page: set the admin password and the monitors there.
This browser cannot talk to USB devices: use Chrome or Edge on a computer. The page must be opened over HTTPS.

Already installed? Connect also changes the Wi-Fi network of a running picoKVM.

Installing fails to connect? Firmware older than this installer, or none, cannot be reached that way: hold BOOT, press RESET, release BOOT, then Connect again.
